# پروژه‌ی مدیریت کتابخانه با Django

## معرفی

این پروژه یک برنامه‌ی آموزشی تحت وب برای مدیریت کتابخانه است.
اطلاعات در لیست‌ها و دیکشنری‌های پایتون نگهداری می‌شوند.

## امکانات

- نمایش فهرست کتاب‌ها و وضعیت موجودبودن آن‌ها
- جست‌وجوی کتاب بر اساس عنوان یا نویسنده
- نمایش اعضا
- افزودن کتاب جدید
- ثبت امانت و جلوگیری از امانت مجدد کتابِ در امانت
- ثبت بازگشت کتاب
- نمایش امانت‌های فعال و سوابق بازگردانده‌شده‌ی هر عضو
- نمایش آمار و پرامانت‌ترین کتاب‌ها

## ساختار اصلی

- `config/`: تنظیمات و مسیرهای اصلی پروژه
- `library/sample_data.py`: داده‌های نمونه
- `library/views.py`: پردازش درخواست‌ها و منطق برنامه
- `library/urls.py`: مسیرهای برنامه
- `library/templates/library/`: قالب‌های HTML
- `requirements.txt`: وابستگی‌ها و نسخه‌های آن‌ها
- `TEST_CHECKLIST.md`: نتایج آزمایش دستی

## اجرای پروژه در ویندوز

پایتون باید روی سیستم نصب باشد.
ترمینال را در پوشه‌ای باز کنید که فایل manage.py داخل آن است.

### ساخت محیط مجازی

```powershell
python -m venv .venv
```

### نصب وابستگی‌ها

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### اجرای سرور توسعه

```powershell
.\.venv\Scripts\python.exe manage.py runserver
```

سپس این آدرس را در مرورگر باز کنید:

http://127.0.0.1:8000/

در این روش، فعال‌کردن محیط مجازی با Activate.ps1 لازم نیست.

## مسیرهای اصلی

| مسیر | کاربرد |
|---|---|
| `/` | صفحه‌ی اصلی |
| `/books/` | فهرست و جست‌وجوی کتاب‌ها |
| `/books/add/` | افزودن کتاب |
| `/members/` | فهرست اعضا |
| `/members/1/history/` | نمونه‌ی تاریخچه‌ی عضو شماره‌ی ۱ |
| `/borrow/` | امانت کتاب |
| `/return/` | بازگشت کتاب |
| `/statistics/` | آمار کتابخانه |

## روش نگهداری داده‌ها

اطلاعات هنگام اجرای برنامه در لیست‌ها و دیکشنری‌های پایتون
نگهداری می‌شوند و پس از ثبت کتاب، امانت یا بازگشت، در data.json
ذخیره می‌شوند.

هنگام اجرای دوباره، اطلاعات از همین فایل بارگذاری می‌شوند.
داده‌های sample_data.py فقط هنگام نبودن data.json استفاده می‌شوند.

این نسخه برای تمرین و اجرای محلی طراحی شده و ذخیره‌سازی آن
برای استفادهٔ هم‌زمان چند فرایند مناسب نیست.

## نکته درباره‌ی آمار

مقادیر اولیه‌ی borrow_count شامل شمارنده‌های نمونه هستند.
لیست borrowings فقط بخشی از سوابق نمونه را دارد؛ بنابراین تعداد
رکوردهای این لیست الزاماً با مجموع borrow_count برابر نیست.

## آزمایش

مراحل آزمایش دستی و نتیجه‌ی آن‌ها در TEST_CHECKLIST.md ثبت می‌شوند.
فقط آزمایش‌هایی که واقعاً موفق بوده‌اند علامت زده می‌شوند.

## معرفی نسخهٔ وب کتابخانه

این پروژه با Django ساخته شده است. رابط کاربری فارسی و راست‌به‌چپ
است و در موبایل و دسکتاپ نمایش متناسب دارد.

### امکانات

- نمایش و جست‌وجوی کتاب‌ها بر اساس عنوان یا نویسنده
- افزودن کتاب جدید
- نمایش اعضای کتابخانه
- ثبت امانت و بازگشت کتاب
- مشاهدهٔ سابقهٔ امانت هر عضو
- نمایش آمار کتابخانه و پرامانت‌ترین کتاب‌ها
- ذخیرهٔ اطلاعات کتابخانه در data.json

### فناوری‌ها

- Python و Django برای پردازش درخواست‌ها
- قالب‌های Django و HTML برای ساخت صفحات
- Tailwind CSS و CSS اختصاصی برای طراحی
- JSON برای ذخیرهٔ اطلاعات کتابخانه

### اجرای محلی در ویندوز

دستورها را در پوشه‌ای اجرا کنید که manage.py داخل آن است.

با فرض آماده بودن محیط مجازی و نصب وابستگی‌ها:

```powershell
.\.venv\Scripts\python.exe manage.py runserver
```
